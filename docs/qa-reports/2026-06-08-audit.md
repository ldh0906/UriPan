## P1 — 프로덕션 영향, 우선 수정

1. ⭐ **시간 저장 시 UTC 변환 누락 → 9시간 밀림** — `board_repository.dart:775,805`
   `createItem`/`updateItem`에서 로컬 `DateTime`에 `.toIso8601String()`(오프셋 없음)을 그대로 저장. Supabase `timestamptz`가 UTC로 해석 → read에서 `toLocal()` +9h. **KST 09:00 일정이 18:00으로 보임.** 모든 일정/할일 시간에 영향. 최근 read-side `toLocal` 픽스가 이 버그를 일관되게 가시화함. → `.toUtc().toIso8601String()` 필요. (확신도 높음)

2. ⭐ **월간 달력 ‘이전/다음 달’이 달을 건너뜀** — `today_board_screen.dart:~430-448`
   `DateTime(year, month±1, selectedDay)`에서 `selectedDay=31`이면 짧은 달에서 오버플로(1/31→3/3). 월간 펼침 + 말일 선택 후 달 이동 시 재현. → 이동 시 day를 1로 정규화하거나 말일 클램프. (확신도 높음)

3. **마지막 보드 leave/로그아웃 시 옛 로컬 알림 미취소** — `board_home_screen.dart:250` (+dispose 62, signOut 191)
   `_syncRemindersIfNeeded`가 `activeBoard==null`이면 early-return → `sync([])` 미호출. 보드를 다 나가거나 로그아웃해도 이전 보드 일정/할일 알림이 계속 울림. → null/로그아웃 경로에서 `scheduler.sync(const [])`. (확신도 높음)

4. **댓글 추가/삭제에 stale 가드 없음 → 보드전환 중 옛 items 덮어씀** — `board_session_controller.dart:317-329`
   다른 item 액션과 달리 `addComment`/`deleteComment`가 stale-request/`activeBoard.id` 가드 없이 `loadBoardItems(board.id)`를 `_items`에 대입. 보드 A 댓글 요청 중 B 전환 시 A items가 B 화면/알림에 반영. (확신도 높음)

5. ⭐ **미래 시각이 “방금”으로 표시** — `friendly_date.dart:27`
   `friendlyRelativeTime`이 음수 차이(미래)에도 `seconds < 60`에 걸림. 기기 시계가 서버보다 느리거나 createdAt이 미래인 댓글에서 발생. → 음수 가드. (확신도 높음)

6. **댓글 로드 실패 시 빈상태+에러 동시 표시** — `comment_thread.dart:202`
   `_comments.isEmpty` 분기가 에러보다 먼저 렌더 → 실패가 “아직 댓글이 없어요”처럼 보임. (메모리상 기존 미해결 폴리시 항목과 동일.) (확신도 높음)
