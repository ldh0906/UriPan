## 깨끗하게 확인된 영역
- 알림: `buildReminderPlan` 안정 id(`item.id:kind` hash & 0x7fffffff)·30일 캡·60건 캡, `LocalNotificationScheduler.sync`의 cancelAll+재예약(로그아웃/보드전환 잔존 없음), 과거시각 스킵.
- realtime: board_items/board_members/boards/item_comments/item_confirmations 전부 board_id(또는 id) eq 필터, 보드 전환 시 `clear()`로 채널 정리. 상세시트 per-item 댓글 구독 dispose/mounted 가드.
- 상태머신: 모든 mutation에 `_nextStateRequest`/`_isCurrentStateRequest`+board id 재확인, `_safeNotify`.
- 캘린더: `calendarWeekBars` 레인 배치·클리핑·rounded 경계, `moveCalendarMonth` 말일 클램프, `startOfCalendarWeek` 일요일 시작, `_calendarDateOnly`/`_taskDateOnly` toLocal 정규화.
- 인증: 합성 이메일 변환(`AuthInputValidator`), keepSignedIn 로그인/가입 양쪽 저장, 이미가입 식별.
- RLS/RPC: item child 트리거 security definer + search_path 고정, 댓글 insert/delete own-or-admin, 확인 insert own+member.
