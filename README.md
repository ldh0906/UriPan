# UriPan

**UriPan**은 가족, 친구, 룸메이트, 스터디, 팀플처럼  
가까운 사람들끼리 일정, 할 일, 공지를 함께 관리하는 공유 보드 앱입니다.

> 흘러가는 채팅방 대신, 우리끼리 확인할 수 있는 작은 상황판.

## 소개

단톡방에서는 중요한 일정이나 할 일이 쉽게 묻힙니다.

“그거 말했잖아.”  
“언제?”  
“단톡에 올렸는데?”  
“못 봤는데?”

UriPan은 이런 상황을 줄이기 위해 만들고 있습니다.

이 앱은 단순한 캘린더가 아니라,  
작은 그룹이 함께 움직이기 위한 **공유 일정판이자 할 일 보드**입니다.

## 핵심 아이디어

UriPan의 목표는 복잡한 기능을 많이 넣는 것이 아닙니다.

가장 중요한 것은 이것입니다.

> 오늘 우리에게 무슨 일정이 있고, 누가 무엇을 해야 하며, 어떤 공지를 확인해야 하는지 한눈에 보여주는 것.

즉, UriPan은 작은 그룹을 위한 **우리만의 운영판**입니다.

## 주요 기능

### 오늘 보드

오늘 그룹에서 확인해야 할 내용을 한곳에 보여줍니다.

- 오늘의 일정
- 오늘의 할 일
- 중요한 공지
- 확인한 멤버와 아직 확인하지 않은 멤버

### 공유 캘린더

그룹 구성원들이 함께 보는 캘린더입니다.

- 월간 일정 보기
- 멤버별 색상 표시
- 그룹 전체 일정 관리

### 할 일 보드

누가 무엇을 맡았는지 쉽게 확인할 수 있습니다.

- 할 일 등록
- 담당자 지정
- 완료 체크
- 역할 분담 확인

### 공지 확인

채팅방에서 사라지기 쉬운 중요한 내용을 따로 관리합니다.

- 공지 등록
- 확인 여부 표시
- 미확인 멤버 확인

## 사용 대상

UriPan은 이런 사람들이 사용할 수 있습니다.

- 가족
- 친구 모임
- 룸메이트
- 스터디 그룹
- 대학교 팀플
- 동아리
- 소규모 커뮤니티

## MVP 범위

첫 번째 버전에서는 작지만 완성도 있는 기능에 집중합니다.

- 그룹 만들기
- 멤버 초대
- 일정 등록
- 할 일 등록
- 공지 등록
- 오늘 보드 확인
- 월간 캘린더 확인
- 공지 확인 처리

## MVP에서 제외할 기능

처음부터 모든 기능을 넣지는 않습니다.

아래 기능들은 추후 확장 대상으로 둡니다.

- 채팅
- 푸시 알림
- 구글 캘린더 연동
- 파일 업로드
- 결제 기능
- AI 일정 추천
- 복잡한 권한 시스템

## 프로젝트 목표

이 프로젝트는 AI-assisted coding을 활용해 만드는 개인 프로젝트입니다.

목표는 거대한 서비스를 한 번에 만드는 것이 아니라,  
작은 그룹이 실제로 사용할 수 있는 MVP를 완성하는 것입니다.

UriPan이 해결하려는 문제는 단순합니다.

> 우리끼리 공유해야 할 일정, 할 일, 공지가 흩어지지 않게 하는 것.
