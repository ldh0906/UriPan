# UriPan

UriPan은 가까운 사람들이 일정, 할 일, 공지를 한 화면에서 함께 확인하는 작은 공유 보드입니다.

첫 버전은 로그인이나 원격 동기화보다 “오늘 무엇을 봐야 하는지”를 빠르게 보여주는 데 집중합니다.

## v1 범위

- 오늘 보드
- 일정 목록
- 할 일 목록
- 공지 목록
- 로컬/메모리 기반 데이터 구조
- Flutter widget smoke test
